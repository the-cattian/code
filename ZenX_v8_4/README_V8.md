# ZenX v8 — compatibility update

Install: unzip, open chrome://extensions, enable Developer mode, disable the old ZenX, Load unpacked and select the ZenX_v7 folder inside this package. Refresh Zendesk.

Changes: new Straw Hat Dawn, King of Hell, and Moonlit Swordsman themes; selectors for the supplied November 2026 Zendesk header and tabs; SLA countdown refresh on tab focus/visibility restoration. Original bookmarklet-based SLA evaluation remains unchanged.

Important: The supplied Zendesk HTML is a saved production DOM snapshot, not a runnable Zendesk application. These changes have passed static syntax/parity checks, but have NOT been visually compared against the authenticated live site. A pixel-perfect match cannot be confirmed offline. Your right-hand Oracle iframe remains controlled by its own application. The 1/2/5 minute timer rules are custom bookmarklet rules, not Zendesk contractual SLA.

Only install if your employer permits personal extensions.
